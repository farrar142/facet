# 클립보드 사람 확인 목록

화면과 다른 프로그램이 걸린 부분은 자동 테스트가 보지 못한다. 복사·붙여넣기·경로 복사(Ctrl+C·Ctrl+V·Ctrl+Shift+C)를
바꿨으면 Windows 기계에서 아래를 직접 돈다. 코어 동작은 `crates/facet-core/tests/clipboard_commands.rs`가 확인한다.

## facet에서 복사 → 다른 프로그램에 붙여넣기

- [ ] facet에서 파일 하나를 골라 Ctrl+C → 탐색기 폴더에서 Ctrl+V: 파일이 복사된다(원본은 그대로).
- [ ] 파일 여러 개와 폴더를 골라 Ctrl+C → 탐색기에 Ctrl+V: 모두 복사된다.
- [ ] 한글·이모지·260자 넘는 경로의 파일도 같다.
- [ ] 파일을 Ctrl+C → 메일 앱 새 메일 본문(또는 첨부 영역)에 Ctrl+V: 첨부된다.
- [ ] 파일을 Ctrl+C → 채팅 앱(카카오톡·Slack·Teams 등) 입력란에 Ctrl+V: 파일 전송 확인이 뜬다.
- [ ] 한글 입력기가 한글 모드여도 Ctrl+C·Ctrl+V가 같다.
- [ ] 선택 없이 Ctrl+C: 커서 항목이 복사된다. 항목이 없는 빈 폴더에서는 아무 일도 없다(명령 팔레트에서 꺼진 채 보임).
- [ ] 상태 줄에 「항목 N개를 복사했습니다」가 보인다.

## 경로 복사

- [ ] 파일 둘을 골라 Ctrl+Shift+C → 메모장에 Ctrl+V: 전체 경로가 큰따옴표로 감싸져 한 줄에 하나씩 붙는다.
- [ ] 선택 없이 Ctrl+Shift+C: 현재 폴더 경로 하나가 붙는다.

## 탐색기에서 잘라내기 → facet 붙여넣기

- [ ] 탐색기에서 파일을 Ctrl+X → facet 폴더에서 Ctrl+V: 이동 작업이 돌고 끝나면 **탐색기의 원본이 사라진다**.
- [ ] 끝난 뒤 다시 Ctrl+V: 꺼져 있다(클립보드가 비었다). 명령 팔레트에서도 「붙여넣기」가 흐리다.
- [ ] Ctrl+Z: 이동이 되돌아가 원본 자리에 파일이 돌아온다.
- [ ] 탐색기에서 Ctrl+C(복사) → facet에서 Ctrl+V: 복사 작업이고 원본은 그대로다.
- [ ] 같은 폴더에서 Ctrl+C → Ctrl+V: 「- 복사본」이 생긴다.
- [ ] 폴더 하나를 선택하고 Ctrl+V: 그 폴더 안에 붙는다. 선택이 없거나 파일이면 현재 폴더에 붙는다.
- [ ] 이름이 같은 항목이 있으면 작업 영역에 이름 충돌 질문이 뜬다.

## 붙여넣기가 꺼지는 경우

- [ ] 글자(메모장에서 Ctrl+C)나 그림만 클립보드에 있을 때 facet의 붙여넣기는 꺼져 있다.
- [ ] 메일 첨부 같은 가상 파일(실제 파일이 아닌 것)을 복사했을 때도 꺼져 있다.
- [ ] 이름 입력란(F2)·주소창·명령 팔레트에서 Ctrl+C·Ctrl+V는 글자 편집이다(파일 복사가 아니다).
