# 0003. 인덱싱은 MFT/USN을 읽는 권한 분리 서비스가 한다

- 상태: 채택
- 날짜: 2026-11-15

## 맥락

빠른 인덱싱과 검색은 필수 요구다. 수백만 파일을 몇 초에 인덱싱하고 변경을 즉시 반영하려면 NTFS의 MFT를 직접 읽고 USN 저널을 따라가야 한다. 이는 볼륨 핸들을 여는 일이라 관리자 권한이 필요하다.

## 결정

- 설치 때 한 번 승인받는 작은 Windows 서비스가 MFT와 USN 저널을 읽어 인덱스를 만든다.
- UI 프로세스는 일반 권한으로 돌고, 서비스에 파이프로 질의한다.
- 서비스가 없거나 닿지 않으면 일반 API로 폴더를 순회하고 변경을 감시하는 방식으로 강등한다.

## 검토한 대안

- **앱 전체를 관리자로 실행**: 실행마다 UAC가 뜨고, 일반 앱과 드래그 앤 드롭이 막히며, 셸 확장이 관리자 권한으로 로드된다.
- **폴더 순회와 변경 감시만**: 첫 인덱싱이 수 분 걸리고, 앱이 꺼진 동안의 변경은 다시 순회해야 한다.
- **Windows Search 인덱스**: 범위가 사용자 설정에 묶이고 질의가 느리다.

## 결과

- 설치 프로그램이 필요하고, 서비스의 수명(설치·업데이트·제거)을 관리해야 한다.
- 서비스는 권한 경계다. 파이프로 받는 질의는 호출자가 읽을 수 없는 경로를 드러내지 않도록 검토해야 한다.
- NTFS가 아닌 볼륨(네트워크·클라우드·exFAT)은 이 방식으로 인덱싱할 수 없다.
