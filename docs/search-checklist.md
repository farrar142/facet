# 검색창·실시간 탐색 화면 확인 목록

화면은 자동 테스트하지 않는다(#206). 사람이 Windows 기계에서 확인한다. 코어의 탐색·결과 위치는 `crates/facet-core/tests/live_search.rs`·`search_results.rs`가 지킨다.

| # | 할 일 | 기대 결과 |
| - | ----- | --------- |
| 1 | Ctrl+F, 그리고 Ctrl+E(한글 모드에서도) | 활성 패널의 주소창 아래에 검색창이 열리고 포커스를 받는다. 이미 열려 있으면 포커스만 다시 오고 전체가 선택된다 |
| 2 | 명령 팔레트(Ctrl+Shift+P)에서 「검색」 | 같은 검색창이 열린다 |
| 3 | 검색창에서 「보고서」를 치고 Enter | 탭이 결과 위치가 되고 탭 제목·주소창 마지막 조각이 「검색: 보고서」다. 결과가 흘러 들어온다 |
| 4 | 한글 모드에서 조합 중인 글자가 있을 때 Enter | 조합이 끝난 글자까지 반영해 검색한다 |
| 5 | 검색창에서 Ctrl+Z | 글자 편집만 되돌린다(작업 실행취소가 아니다) |
| 6 | 「내용」을 누른다 | 「내용」이 굵게 되고 파일 이름 조건 입력란과 「☐ 정규식」이 더해진다. 「이름」을 누르면 사라진다 |
| 7 | `C:\Windows`에서 `dll`을 찾는다 | 목록이 흐르듯 채워지고 그동안 창이 멈추지 않는다(스크롤·탭 전환·창 끌기가 부드럽다) |
| 8 | 탐색 중 목록 위 띠 | 「탐색 중… n개 찾음 · 폴더 m개 훑음」이 늘어난다. 「중지」 단추가 있다 |
| 9 | 끝난 뒤 띠 | 「탐색 끝 · n개 찾음 · 건너뛴 폴더 k개 · 걸린 시간」이 보이고 중지 단추는 없다 |
| 10 | 탐색 중 「중지」 단추 | 멈추고 「중지함 …」이 보이며 이미 온 결과는 남는다 |
| 11 | 탐색 중 목록을 눌러 키보드를 목록에 두고 Esc | 같이 멈춘다 |
| 12 | 탐색 중 폴더 이동(주소창·뒤로 등) | 탐색이 저절로 멈추고 결과 목록이 사라진다. 탭을 닫아도 같다 |
| 13 | 결과 목록의 「위치」 열 | 항목이 든 폴더 경로가 보이고 머리글을 누르면 정렬(▲▼), 경계를 끌면 너비가 바뀐다 |
| 14 | 결과에서 선택·Ctrl+A·사각형 선택·키보드 이동 | 폴더 목록과 같다. 같은 이름 다른 폴더의 항목을 따로 고른다 |
| 15 | 결과에서 복사(Ctrl+C)·붙여넣기(다른 탭)·삭제(Delete)·Ctrl+Z | 항목마다 제 폴더 경로로 동작한다. 삭제한 항목은 목록에서 빠지고 실행취소하면 휴지통에서 돌아온다 |
| 16 | 결과에서 항목을 오른쪽 클릭 | 메뉴 첫머리에 「폴더에서 보기」와 구분선이 있다 |
| 17 | 「폴더에서 보기」 | 같은 탭에서 그 항목의 폴더가 열리고 그 항목이 선택돼 있다 |
| 18 | 17 뒤 Alt+←(뒤로) | 결과 위치로 돌아와 같은 검색을 다시 한다 |
| 19 | 결과 위치에서 뒤로(Alt+←) | 검색하기 전 폴더로 간다 |
| 20 | 결과 항목을 끌어 반대편 패널이나 탐색기에 놓기 | 폴더 목록과 같이 복사·이동된다 |
| 21 | 결과에서 Enter(폴더·파일) | 폴더는 그 경로로 들어가고 파일은 기본 프로그램으로 열린다 |

## 내용 검색(#208)

코어는 `crates/facet-core/tests/content_search_results.rs`·`content_search.rs`가 지킨다.

| # | 할 일 | 기대 결과 |
| - | ----- | --------- |
| 22 | 명령 팔레트(Ctrl+Shift+P)에서 「내용 검색」 | 검색창이 「내용」으로 열리고 포커스를 받는다(단축키는 없다) |
| 23 | 「내용」에서 찾을 글자를 치고 Enter | 타자마다 시작하지 않고 Enter에서만 시작한다. 탭 제목·주소창이 「검색: 글자」가 된다 |
| 24 | 파일 이름 조건에 `*.txt`를 넣고 Enter | `.txt` 파일 안에서만 찾는다 |
| 25 | 결과 목록의 「일치」 열 | 「n회 · 첫 일치 줄」이 보이고 머리글을 누르면 일치 수로 정렬(▲▼), 경계를 끌면 너비가 바뀐다 |
| 26 | 「☐ 정규식」을 눌러 켜고 `(열리지`처럼 틀린 식으로 Enter | 위치가 그대로이고(뒤로 기록도 그대로) 검색창 아래에 「정규식이 올바르지 않습니다: …」가 보인다 |
| 27 | 한글 모드에서 한글 글자를 치고 Enter | 조합이 끝난 글자까지 반영해 찾는다 |
| 28 | 바이너리 파일·너무 큰 파일이 든 폴더에서 검색한 뒤 띠 | 「… · 건너뛴 파일: 바이너리 n, 큰 파일 m …」처럼 종류별 수가 보인다 |
| 29 | OneDrive 폴더(온라인 전용 파일이 든)에서 내용 검색 | 온라인 전용 항목은 「건너뛴 파일: 온라인 전용 n」에 세고, **내려받지 않는다**(파일 탐색기의 상태 아이콘이 구름 그대로이고 OneDrive가 다운로드를 시작하지 않는다) |
| 30 | 내용 검색 결과에서 「중지」·Esc·다른 폴더로 이동·탭 닫기·뒤로·F5 | 이름 검색 결과와 같다(F5는 같은 검색을 처음부터 다시 한다) |
| 31 | 내용 검색 결과에서 「폴더에서 보기」·삭제·Ctrl+Z | 이름 검색 결과와 같이 동작한다 |

## 질의 문법(이름 검색, #222)

코어는 `crates/facet-core/tests/live_search_condition.rs`·`query_syntax.rs`가 지킨다. 「이름」 검색창에서 Enter로 확인한다.

| # | 할 일 | 기대 결과 |
|---|-------|-----------|
| 32 | `보고서 pdf` | 이름에 두 낱말이 모두 든 항목만(그리고) |
| 33 | `보고서\|초안` | 둘 중 하나가 든 항목 |
| 34 | `보고서 !초안` | 「보고서」가 있고 「초안」이 없는 항목 |
| 35 | `"my docs"` 와 `*.txt` | 구절은 공백 그대로 부분 일치, `*.txt`는 이름 전체 와일드카드 |
| 36 | `ext:jpg;png size:>1mb` | 1MB보다 큰 jpg·png |
| 37 | `dm:thisweek file:` | 이번 주에 고친 파일(폴더는 빠짐) |
| 38 | `path:docs\` , `regex:^r.*\.txt$` , `folder:` | 경로·정규식·폴더만 조건이 듣는다 |
| 39 | `<보고서\|초안> ext:docx` | 묶기가 들은 결과 |
| 40 | `보고서 <초안`(틀린 문법) | 위치·기록이 그대로이고 검색창 아래에 「검색어가 올바르지 않습니다 (n번째 글자): …」가 보인다 |
