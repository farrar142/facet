# 끌어 놓기 사람 확인 목록

화면과 다른 프로그램이 걸린 부분은 자동 테스트가 보지 못한다. 다른 앱에서 facet으로 끌어 놓기(OLE 드롭 대상)를
바꿨으면 Windows 기계에서 아래를 직접 돈다. 드롭 대상 래퍼는 `crates/facet-win/tests/drop_target.rs`, 결과 결정과 작업은
`crates/facet-core/tests/dragdrop.rs`, 놓을 자리는 `crates/facet-app/src/file_drop.rs`의 단위 테스트가 확인한다. 결정의
근거는 `docs/adr/0008-ole-drop-target-per-window.md`.

## 탐색기 → facet (왼쪽 버튼)

- [ ] 같은 볼륨(예: `C:`의 탐색기 → facet의 `C:` 폴더)에서 파일을 끌어 facet 목록 빈 곳에 놓기: 커서가 「이동」이고, 작업
      영역에 이동 진행 표시가 생기며, 끝나면 탐색기의 원본이 사라진다. 탐색기가 따로 원본을 지우려 하지 않는다(오류 대화
      없음).
- [ ] 다른 볼륨(예: `D:` → `C:`)에서 끌기: 커서가 「복사」이고 복사 작업이 돌며 원본은 그대로다.
- [ ] 같은 볼륨에서 **Ctrl**을 누른 채 놓기: 복사. 다른 볼륨에서 **Shift**를 누른 채 놓기: 이동(원본이 사라짐). 끄는 동안
      키를 누르고 떼면 커서가 그때그때 바뀐다.
- [ ] facet의 **폴더 행 위**로 끌면 그 행이 강조되고, 놓으면 그 폴더 안으로 들어간다. 파일 행 위에서는 금지 커서이고 강조가
      없다. 목록 빈 곳·머리글·주소창·탭 줄 위는 그 패널의 지금 위치로 들어간다.
- [ ] 패널을 나눈 창에서 오른쪽·왼쪽 패널에 각각 놓으면 그 패널의 위치로 들어간다. 작업 영역·상태 표시줄 위는 금지 커서다.
- [ ] 끄는 동안 강조가 마우스를 따라 끊김 없이 움직인다(창이 다시 그려진다). 창 밖으로 나가면 강조가 사라진다.
- [ ] 원본이 이미 그 폴더 안에 있는 이동(같은 폴더로 끌기)은 금지 커서다. Ctrl을 누르면 복사가 되어 「- 복사본」이 생긴다.
- [ ] 폴더를 자기 하위 폴더로 끌면 금지 커서다.
- [ ] 이름이 같은 항목이 있으면 작업 영역에 이름 충돌 질문이 뜬다.
- [ ] 놓은 뒤 **Ctrl+Z**: 이동은 원본 자리로 되돌아가고, 복사는 사본이 휴지통으로 간다.
- [ ] 큰 폴더(수천 개)를 놓아도 탐색기가 멈추지 않고 곧바로 돌아온다(복사는 facet 작업 영역에서 이어 돈다).
- [ ] 탐색기의 끌기 그림(파일 아이콘과 개수)이 facet 창 위에서도 보인다.

## 오른쪽 버튼

- [ ] 탐색기에서 오른쪽 버튼으로 끌어 facet에 놓기: 이번 판에서는 금지 커서이고 아무 일도 없다(고르기 메뉴는 다음 티켓).

## 파일이 아닌 데이터

- [ ] 브라우저(Edge·Chrome)에서 **그림**을 끌어 facet에 놓기: 금지 커서이고 아무 일도 없다.
- [ ] 브라우저에서 **글자**(고른 문장)나 링크를 끌기: 금지 커서.
- [ ] 메일 앱의 첨부(가상 파일)를 끌기: 금지 커서.

## 창 여럿

- [ ] Ctrl+N으로 창을 둘 열고 각 창에 탐색기에서 끌어 놓기: 두 창 모두 받는다. 놓은 창이 활성 창이 된다.
- [ ] 탭을 창 밖에 놓아 생긴 창, 세션에서 되살린 창도 받는다.
