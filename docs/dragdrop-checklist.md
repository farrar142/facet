# 끌어 놓기 사람 확인 목록

화면과 다른 프로그램이 걸린 부분은 자동 테스트가 보지 못한다. 끌어 놓기(OLE 드롭 대상, facet 항목 끌기)를 바꿨으면
Windows 기계에서 아래를 직접 돈다. 드롭 대상 래퍼는 `crates/facet-win/tests/drop_target.rs`, 끌기 원본의 데이터 개체와
드롭 설명은 `crates/facet-win/tests/drag_source.rs`, 결과 결정과 작업은 `crates/facet-core/tests/dragdrop.rs`, 놓을 자리는
`crates/facet-app/src/file_drop.rs`, 누르기와 끌기 구분은 `crates/facet-app/src/item_drag.rs`, 고르기 메뉴는
`crates/facet-app/src/drop_menu.rs`의 단위 테스트가 확인한다. 결정의 근거는 `docs/adr/0008-ole-drop-target-per-window.md`와
`docs/adr/0009-item-drag-source.md`.

## 탐색기 → facet (왼쪽 버튼)

- [ ] 같은 볼륨(예: `C:`의 탐색기 → facet의 `C:` 폴더)에서 파일을 끌어 facet 목록 빈 곳에 놓기: 커서가 「이동」이고, 작업
      영역에 이동 진행 표시가 생기며, 끝나면 탐색기의 원본이 사라진다. 탐색기가 따로 원본을 지우려 하지 않는다(오류 대화
      없음).
- [ ] 다른 볼륨(예: `D:` → `C:`)에서 끌기: 커서가 「복사」이고 복사 작업이 돌며 원본은 그대로다.
- [ ] 같은 볼륨에서 **Ctrl**을 누른 채 놓기: 복사. 다른 볼륨에서 **Shift**를 누른 채 놓기: 이동(원본이 사라짐). 끄는 동안
      키를 누르고 떼면 커서가 그때그때 바뀐다.
- [ ] facet의 **폴더 행 위**로 끌면 그 행이 강조되고, 놓으면 그 폴더 안으로 들어간다. 파일 행 위에서는 금지 커서이고 강조가
      없다. 목록 빈 곳·머리글·주소창·탭 줄 위는 그 패널의 지금 위치로 들어간다.
- [ ] 패널을 나눈 창에서 오른쪽·왼쪽 패널에 각각 놓으면 그 패널의 위치로 들어간다. 작업 영역·상태 표시줄 위는 금지 커서다.
- [ ] 끄는 동안 강조가 마우스를 따라 끊김 없이 움직인다(창이 다시 그려진다). 창 밖으로 나가면 강조가 사라진다.
- [ ] 원본이 이미 그 폴더 안에 있는 이동(같은 폴더로 끌기)은 금지 커서다. Ctrl을 누르면 복사가 되어 「- 복사본」이 생긴다.
- [ ] 폴더를 자기 하위 폴더로 끌면 금지 커서다.
- [ ] 이름이 같은 항목이 있으면 작업 영역에 이름 충돌 질문이 뜬다.
- [ ] 놓은 뒤 **Ctrl+Z**: 이동은 원본 자리로 되돌아가고, 복사는 사본이 휴지통으로 간다.
- [ ] 큰 폴더(수천 개)를 놓아도 탐색기가 멈추지 않고 곧바로 돌아온다(복사는 facet 작업 영역에서 이어 돈다).
- [ ] 탐색기의 끌기 그림(파일 아이콘과 개수)이 facet 창 위에서도 보인다.

## 탭 위·주소창 조각 위

- [ ] 항목(탐색기에서 온 것, facet 항목)을 **다른 탭 위**로 끌면 그 탭이 강조되고 「〈폴더〉로 이동/복사」가 보인다. 놓으면 그
      탭의 위치로 들어간다(활성 탭은 그대로).
- [ ] 다른 탭 위에 **0.5초 머물면** 그 탭이 활성 탭이 되어 목록이 보이고, 계속 끌어 그 목록의 폴더 행이나 빈 곳에 놓을 수
      있다. 탭 줄을 빠르게 지나가면 탭이 열리지 않는다. 탭을 떠났다 돌아오면 다시 0.5초를 센다.
- [ ] 주소창의 **경로 조각 위**로 끌면 그 조각이 강조되고, 놓으면 그 상위 폴더로 들어간다.
- [ ] 폴더를 자기 자신이나 자기 하위를 가리키는 경로 조각·탭 위에 놓으면 금지 커서다.
- [ ] 탭을 끌어 순서를 바꾸거나 다른 패널·창으로 옮기는 것은 전과 같이 된다.

## 오른쪽 버튼

- [ ] 탐색기에서 오른쪽 버튼으로 끌어 facet 폴더 행·빈 곳에 놓기: 탐색기가 곧바로 풀려나고(멈추지 않음) 놓은 자리에
      「여기에 복사」「여기로 이동」「취소」 메뉴가 뜬다. 처음 고른 줄은 기본 효과(같은 볼륨이면 이동)다. 고르면 작업 영역에
      작업이 생기고 Ctrl+Z로 되돌아간다. 「취소」·Esc·바깥 누르기는 아무것도 하지 않는다. 탐색기는 원본을 따로 지우지 않는다.
- [ ] 원본이 이미 그 폴더 안이면 「여기로 이동」이 꺼져 있다.

## 파일이 아닌 데이터

- [ ] 브라우저(Edge·Chrome)에서 **그림**을 끌어 facet에 놓기: 금지 커서이고 아무 일도 없다.
- [ ] 브라우저에서 **글자**(고른 문장)나 링크를 끌기: 금지 커서.
- [ ] 메일 앱의 첨부(가상 파일)를 끌기: 금지 커서.

## 창 여럿

- [ ] Ctrl+N으로 창을 둘 열고 각 창에 탐색기에서 끌어 놓기: 두 창 모두 받는다. 놓은 창이 활성 창이 된다.
- [ ] 탭을 창 밖에 놓아 생긴 창, 세션에서 되살린 창도 받는다.

## facet → facet (항목 끌기)

- [ ] 항목의 **아이콘·이름 글자 위**에서 왼쪽 버튼으로 끌면 끌기가 시작되고(끌기 그림이 보임), 행의 이름 글자 오른쪽
      여백·다른 칸·목록 아래에서 끌면 전처럼 **사각형 선택**이다.
- [ ] 여러 항목을 고른 뒤 그중 하나의 이름 위에서 끌면 고른 항목 모두가 끌린다. 끌지 않고 놓으면 그 항목 하나만 남는다
      (탐색기와 같다). 선택에 없는 항목을 끌면 그 항목 하나만 끌린다.
- [ ] 패널을 나눈 창에서 **반대편 패널**의 빈 곳에 놓기: 같은 볼륨이면 이동, 다른 볼륨이면 복사. Ctrl은 복사, Shift는 이동.
      작업 영역에 진행 표시가 생기고 Ctrl+Z로 되돌아간다.
- [ ] 같은 목록의 **폴더 행 위**로 끌면 그 행이 강조되고 놓으면 그 폴더 안으로 이동한다.
- [ ] 끄는 동안 커서 옆(끌기 그림 아래)에 「〈폴더〉로 이동」「〈폴더〉로 복사」가 보이고 폴더 이름이 강조된다. Ctrl·Shift를
      누르면 글자가 바뀐다.
- [ ] 폴더를 **자기 자신**(그 폴더 행)이나 **자기 하위**로 끌면 금지 커서와 「폴더를 그 안으로 놓을 수 없음」, **파일 행 위**는
      금지 커서와 「여기에는 놓을 수 없음」. 놓아도 아무 일이 없다. 같은 폴더의 빈 곳은 「이미 이 폴더에 있음」(Ctrl이면
      「- 복사본」으로 복사).
- [ ] **facet 창 다시 그리기**: facet 안에서 끄는 동안 놓일 폴더 행 강조가 마우스를 따라 움직인다(docs/adr/0009). 움직이지
      않으면 그 사실을 적는다(놓기·커서·설명은 그대로여야 한다).
- [ ] Esc를 누르거나 끄는 중에 다른 버튼을 누르면 끌기가 그만둬지고 아무 일도 없다. 끌기가 끝난 뒤 다른 앱 창을 누르면
      그 앱이 받는다(facet이 마우스를 붙잡고 있지 않다).
- [ ] 오른쪽 버튼으로 항목 위를 눌렀다 떼면(끌지 않으면) 전처럼 오른쪽 메뉴가 뜬다. 오른쪽 버튼으로 끌어 반대편 패널·폴더
      행에 놓으면 「여기에 복사」「여기로 이동」「취소」 메뉴가 뜨고 고른 대로 된다.
- [ ] Ctrl+N으로 연 다른 facet 창에 끌어 놓아도 같다.

## facet → 다른 앱

- [ ] facet 항목을 **탐색기** 폴더 창으로 끌기: 탐색기의 설명(「〈폴더〉(으)로 이동/복사」)이 보이고, 놓으면 같은 볼륨은 이동
      (facet 목록에서 사라짐), 다른 볼륨은 복사다. facet이 원본을 따로 지우지 않는다(이동한 뒤 오류 대화 없음).
- [ ] **바탕 화면**으로 끌기: 같다.
- [ ] **메일 앱**(Outlook 등)의 새 메일 창으로 끌기: 첨부가 된다. 받지 않는 앱이 있으면 그 이름을 적는다(ADR-0009: 셸 항목
      목록을 더할지 정한다).
- [ ] 오른쪽 버튼으로 탐색기에 끌어 놓기: 탐색기의 오른쪽 끌기 메뉴가 뜬다.
- [ ] 끄는 동안 facet 창이 멈춘 것처럼 보이지 않는다(작업 영역의 진행 표시가 움직인다).
