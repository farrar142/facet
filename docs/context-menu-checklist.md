# 오른쪽 메뉴 사람 확인 목록

메뉴는 창 위에 facet이 직접 그리므로 자동 테스트가 보지 못하는 부분이 있다. 오른쪽 메뉴(우클릭, Shift+F10, 메뉴 키)를
바꾸거나 Slint·입력 처리 코드를 바꿨으면 Windows 기계에서 아래를 직접 돈다. 메뉴 구성과 오른쪽 클릭의 선택 규칙은
`crates/facet-core/tests/menu.rs`가 확인한다.

## 열기

- [ ] 파일 행을 오른쪽 클릭: 메뉴가 클릭한 자리에 뜬다. 항목 순서는 열기, 새 탭에서 열기(꺼짐), 구분선, 잘라내기, 복사, 붙여넣기(꺼짐), 경로 복사, 구분선, 반대편 패널로 복사·이동, 복사 위치…, 이동 위치…, 구분선, 이름 바꾸기, 삭제다.
- [ ] 폴더 행을 오른쪽 클릭: 「새 탭에서 열기」가 켜진다. 클립보드에 파일이 있으면 「붙여넣기」도 켜지고, 누르면 그 폴더 안에 붙는다.
- [ ] 선택 밖 행을 오른쪽 클릭: 선택이 그 행 하나로 바뀐다. 선택 안 행을 오른쪽 클릭: 선택이 그대로고 메뉴가 선택 전체에 적용된다(삭제 등).
- [ ] 목록 아래 빈 곳을 오른쪽 클릭: 선택이 풀리고 빈 곳 메뉴(붙여넣기, 새 폴더, 정렬 기준 ▶, 숨김 항목 보이기, 새로 고침, 경로 복사)가 뜬다.
- [ ] 패널이 둘일 때 비활성 패널을 오른쪽 클릭: 그 패널이 활성 패널(테두리·주소창 색)이 된다.
- [ ] 항목 옆에 단축키 글자(Ctrl+X, Ctrl+C, F2, Delete …)가 보이고 명령 팔레트의 글자와 같다.
- [ ] 한 번 눌러 연 메뉴가 창 오른쪽·아래 끝 가까이에서도 창 밖으로 넘치지 않고 안쪽으로 옮겨 뜬다.

## 고르기

- [ ] 줄을 누르면 그 명령이 실행되고 메뉴가 닫힌다(복사 → 다른 폴더에서 붙여넣기, 삭제 → 휴지통, 이름 바꾸기 → 이름 입력란).
- [ ] 꺼진 줄은 흐리게 보이고, 마우스를 올려도 강조되지 않고, 눌러도 아무 일이 없다(메뉴는 그대로).
- [ ] 정렬 기준 줄에 마우스를 올리거나 → 를 누르면 하위 메뉴가 오른쪽에 열린다. 지금 정렬 기준에 ▲(오름차순)·▼(내림차순)이 붙는다. 같은 기준을 다시 고르면 방향이 뒤집힌다. 오른쪽에 자리가 없으면 왼쪽에 열린다.
- [ ] 숨김 항목 보이기가 켜져 있으면 ✓가 붙는다.
- [ ] ↑↓로 줄을 옮기면 꺼진 줄과 구분선을 건너뛰고 끝에서 반대편 끝으로 돈다. → 는 하위 메뉴 열기, ← 는 닫기, Enter는 실행, Esc는 메뉴 닫기다.
- [ ] 메뉴 밖을 누르면 닫히고(그 누름이 목록 항목을 고르지는 않는다), 닫힌 뒤 목록 키보드(↑↓ 등)가 다시 된다.

## 키보드로 열기

- [ ] 항목에 커서를 두고 Shift+F10: 커서 항목 바로 아래 옆에 항목 메뉴가 뜬다. 목록 맨 아래 항목이어도 창 안에 뜬다.
- [ ] 메뉴 키(Apps 키, 키보드에 있을 때)도 같다.
- [ ] 커서가 없는 빈 폴더에서 Shift+F10: 목록 왼쪽 위에 빈 곳 메뉴가 뜬다.
- [ ] 한글 입력기가 한글 모드여도 Shift+F10·메뉴 키가 같다.
- [ ] 이름 입력란·주소창에 입력 중일 때 Shift+F10은 facet 메뉴를 열지 않는다(입력란의 동작).
