# 한글 IME 체크리스트

facet의 이름 입력란(F2)에서 한글 입력이 되는지 사람이 Windows 기계에서 확인하는 목록이다. 화면은 자동 테스트하지 않으므로(spec #1의 Testing Decisions) 이 목록이 유일한 확인 수단이다. Slint나 입력 처리 코드를 바꾼 뒤, 그리고 spec이 끝날 때마다 다시 확인한다.

## 준비

1. Windows 설정에서 한국어 입력기(Microsoft 입력기, 두벌식)를 켠다.
2. 시험 폴더를 만들고 앱을 연다.

   ```
   cargo xtask test-folder
   cargo run --release -p facet-app -- %TEMP%\facet-test-folders\items-100000
   ```

   작은 폴더면 아무 폴더나 괜찮다(`cargo run -p facet-app -- <폴더 경로>`).
3. 목록에서 항목 하나를 고르고 F2를 누른다. 그 행의 이름 자리에 현재 이름이 채워지고 전부 선택된 입력란이 뜬다.

이름 입력란은 입력만 확인한다. Enter로 확정하면 창 아래 상태 줄에 「입력한 이름: 「…」」가 보이고, **실제 파일 이름은 바뀌지 않는다**(실제 이름바꾸기는 S4). Esc는 입력을 취소하고 상태 줄에 「이름 입력을 취소했습니다」가 보인다.

## 확인할 것

각 항목을 한 번씩 하고 결과(통과/실패와 본 것)를 적는다. 한 항목이 끝나면 Esc나 Enter로 입력란을 닫고 F2로 다시 연다.

| # | 할 일 | 기대 결과 |
| - | ----- | --------- |
| 1 | 두벌식으로 「새 폴더 가나다」 입력 | 조합 중인 글자가 입력 위치에 보인다. Enter 뒤 상태 줄에 「새 폴더 가나다」가 그대로 보인다 |
| 2 | 「가나다」를 치다가 「다」를 조합하는 중에 Enter | 글자가 한 번만 확정된다(상태 줄에 「가나다」, 「가나다다」가 아니다) |
| 3 | 조합하는 중에 Esc | 입력이 취소되고 남은 글자가 없다. 입력란이 닫히고 목록의 이름은 원래대로다. F2로 다시 열면 원래 이름이 채워져 있다 |
| 4 | 조합하는 중에 ←·→ 방향키, 또는 입력란 안의 다른 위치를 마우스로 클릭 | 조합하던 글자가 확정되고 커서가 옮겨진다. 목록의 선택은 움직이지 않는다 |
| 5 | 한글 한 글자(예: 「한」)를 치고 한자 키 | 한자 후보 창이 입력 위치 근처에 뜨고, 후보를 고르면 그 한자로 바뀐다 |
| 6 | 한/영 키로 영문으로 바꾼 뒤 `New folder` 입력 | 영문이 정상으로 들어가고 남은 한글 조합이 없다 |

## 한글 모드의 단축키

단축키는 입력한 글자가 아니라 키로 맞춘다(코어 `facet_core::command`, #56). 한글 모드에서 H 키는 「ㅗ」를 내지만 Ctrl+H는 영문 모드와 똑같이 동작해야 한다. 키 이벤트 수준은 `crates/facet-core/tests/command.rs`가 확인하고, 실제 IME는 사람이 아래를 본다. 앱이 단축키를 코어의 명령 목록으로 실행하게 된 뒤(#58, #60) 확인한다. 입력란이 닫힌 상태(목록에 키보드 입력이 있는 상태)에서 한/영 키로 한글 모드로 바꾸고 누른다.

| # | 할 일 | 기대 결과 |
| - | ----- | --------- |
| 7 | 한글 모드에서 Ctrl+H | 숨김 항목 보이기/감추기가 바뀐다(영문 모드와 같다). 목록에 「ㅗ」가 들어가거나 글자로 이동이 일어나지 않는다 |
| 8 | 한글 모드에서 Ctrl+L, Alt+D | 주소창이 고쳐 쓰는 모드가 되고 전체 경로가 선택된다 |
| 9 | 한글 모드에서 Ctrl+Shift+P | 명령 팔레트가 열린다 |
| 10 | 한글 모드에서 Ctrl+A | 모든 항목이 선택된다 |

## 글자로 이동

목록에 키보드 입력이 있는 상태(입력란이 닫힘)에서 한글 모드로 친다. 앱은 보이지 않는 입력란으로 키를 받아, IME가 조합을 끝낸 글자만 코어의 글자로 이동(`Tab::type_to_select`)에 넘긴다(#58). 한글 이름 항목(예: 「가나.txt」, 「나비.txt」, 「다리.txt」)이 있는 폴더에서 확인한다.

| # | 할 일 | 기대 결과 |
| - | ----- | --------- |
| 11 | 한글 모드에서 「나」를 치고 다음 글자(예: 스페이스나 다른 자음)로 조합을 끝낸다 | 「나」로 시작하는 항목에 커서가 가고 그 항목이 선택된다. 조합 중인 글자가 화면 어디에도 남지 않는다 |
| 12 | 한글 모드에서 「나비」를 1초 안에 이어 친다 | 「나비」로 시작하는 항목으로 간다 |
| 13 | 한글 모드에서 같은 글자를 거듭 친다 | 그 글자로 시작하는 항목을 차례로 돈다 |
| 14 | 한글 모드에서 Enter·Backspace·↑↓ | 열기·뒤로·커서 이동이 영문 모드와 같다 |

## 함께 볼 것

- 입력란이 열린 동안 ↑↓·Page Up/Down·Home/End가 목록을 움직이지 않는다.
- 입력란이 열린 동안 다른 행을 클릭하면 입력이 확정되고(상태 줄에 보인다) 그 행이 선택된다.
- 어느 경우에도 파일 이름은 바뀌지 않는다(탐색기로 확인).

## 주소창

주소창을 글자로 고쳐 쓰는 모드(#59)도 같은 TextInput 방식이다. 한글 이름 폴더(예: `%TEMP%\facet-한글\가나다`)를 만들어 두고 확인한다.

| # | 할 일 | 기대 결과 |
| - | ----- | --------- |
| 15 | Ctrl+L로 고쳐 쓰는 모드를 열고 끝에 `\가`를 두벌식으로 친다 | 조합 중인 글자가 입력란에 보이고, 조합이 끝나면 「가」로 시작하는 하위 폴더 후보가 아래에 뜬다 |
| 16 | 「가나다」를 조합하는 중에 Enter | 글자가 한 번만 확정되고 그 폴더로 간다(「가나다다」가 아니다) |
| 17 | 조합하는 중에 Esc | 경로 조각 모드로 돌아가고 남은 글자가 없다. 탭은 원래 위치다 |
| 18 | 한글 모드에서 Alt+D, F4 | 고쳐 쓰는 모드가 되고 전체 경로가 선택된다 |

## 기록

결과는 ADR-0002의 「검증 결과」 절(티켓 #9)에 날짜, Windows 버전, 입력기 이름과 함께 적는다.
