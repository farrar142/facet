# 미리보기 영역 체크리스트

화면은 자동 테스트하지 않는다. 사람이 Windows 기계에서 아래를 확인한다(#340, 스펙 #26의 사람용 목록에서 옮김).
Slint나 미리보기 영역 코드를 바꾸면 다시 돈다.

## 켜고 끄기·폭

1. 창에서 Alt+P → 오른쪽 끝에 미리보기 영역이 생긴다. 다시 Alt+P → 사라진다. 명령 팔레트(Ctrl+Shift+P)의 「미리보기 영역」도 같다.
2. 패널을 나눈다(Ctrl+백슬래시) → 영역은 창 오른쪽 끝에 하나이고, Tab으로 활성 패널을 바꾸면 그 패널의 선택을 보인다.
3. 영역 경계를 끌어 넓히고 facet을 닫았다 다시 띄운다 → 켜짐과 폭이 그대로다. Ctrl+N 새 창도 같은 켜짐·폭이다.

## 내용

4. 코드 파일·로그를 고른다 → 고정폭 글꼴로 보이고, 1GB 로그는 「앞 256KB만 보임」과 함께 멈추지 않고 스크롤된다. 한 줄 안의 글자를 끌어 골라 Ctrl+C → 메모장에 붙는다.
5. CP949로 저장한 한글 텍스트가 깨지지 않는다.
6. 폴더를 고르면 이름과 항목 수(세는 동안 「세는 중」), 파일 셋을 고르면 「3개 선택」과 크기 합, 선택이 없으면 안내 문구, `.zip`처럼 미리 볼 수 없는 파일은 아이콘·이름·유형·크기·날짜가 보인다.
7. 공유 없이 열어 둔 파일·권한 없는 파일을 고르면 이유 문구가 영역 안에 보이고 오류 창이 뜨지 않는다. OneDrive 온라인 전용 파일은 「온라인 전용 항목이라 내려받지 않음」이고 내려받기가 일어나지 않는다.
8. 미리 보는 텍스트 파일을 메모장으로 고쳐 저장 → 영역이 새 내용으로 바뀐다. 지우면 「항목이 사라짐」.

## 포커스

9. 영역의 빈 곳을 누르거나 글자 줄을 눌러 골라도, Esc나 목록 누르기 뒤 목록에서 화살표가 다시 움직인다. 영역의 빈 곳을 눌러도 목록의 화살표 이동이 이어진다.

## 시작 속도

10. 영역을 켠 채 `cargo xtask measure` → 콜드 스타트 중앙값 200ms 미만. 영역이 켜진 채 시작해도 첫 목록이 먼저 뜬다.
